# KENTO — Digital Identity

A premium, responsive React + TypeScript portfolio built with Vite, Framer Motion and Lucide icons.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Build for deployment
Run `npm run build`. Upload the generated `dist` folder to Cloudflare Pages, Netlify or Vercel (static deployment).
